## What I built

The reduced bundle carries `{signal_id, negative_capable, query_text, record_count, records_sha256, result}` (plus `failure_class`, the class of a failure and never its message); raw records go to a sibling `.raw.json`. A failed query records `result: failed`, `record_count: null`; `0` is written only by a query that ran to the end. `query_text` is the exact string that is then executed, so it cannot drift from the code. ## Where the brief is wrong

- **Task 1, "no write cmdlet anywhere".** The script has to write its result somewhere. It writes two files through .NET calls into its own output folder and changes nothing in the directory or on the host; the test holds that (no `Set-`/`New-`/`Remove-`/`Add-`/`Enable-`… cmdlets, no credentials).
- **Task 1, the six queries, as given.** `Get-ADUser -Filter {LastLogonDate -lt …}` does not work: `LastLogonDate` is calculated client-side and cannot be filtered on the server, so the script filters on `lastLogonTimestamp`, which replicates lazily (up to about 14 days), and does not return accounts that never logged on. `Get-LocalGroupMember` and `auditpol` read **one host**, not the estate (the local-administrators signal is therefore marked `negative_capable: false`, so it can only lead to Unknown), and `auditpol` needs the right to read the audit policy.
- **Task 3, bundle handling.** As suggested, and it works; the cost is a 490 kB chunk fetched on first click, not a bigger main bundle. One departure from "measured": before the upload the button is disabled and the card carries the project's rule for a before-upload projection (`illustrative`), because a report is made from an assessment.
- **Task 4, `entity_name` in the OSCAL preview and the Word header.** Only the demonstration organisation has an assessment, so those documents can only ever carry its name; a real entity gets the empty state, never an OSCAL or Word document. I carried `entity-name` (and the sector) into both for the demonstration organisation, which is the only case that exists. The listed real organisations are my curation, not checked by NCSC, and listing one is not a statement about it.
